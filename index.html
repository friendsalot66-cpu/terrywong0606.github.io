About Multi-API Chat

Getting Started

This client-side application connects directly to your configured Custom API Providers (OpenAI, Gemini, or Anthropic compatible, such as OmniRoute, DeepSeek, or Ollama). Your keys and settings are stored locally.

  • Step 1: Open Settings (⚙️) → Custom API Providers and add a provider Base URL (e.g., http://127.0.0.1:20128/v1).
  • Step 2: Click the Key icon (🔑) in the sidebar to manage API keys.
  • Step 3: Select a model (🧠) and start chatting.
